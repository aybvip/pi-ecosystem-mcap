# Pi Launchpad و PiRC Token Standard

> هاد الملف يشرح **آلية إطلاق الـTokens** داخل إيكوسستم Pi — مبدأ Product-First، كيفاش تُوزَّع الـTokens، وكيفاش تُبنى السيولة من اليوم الأول.

---

## 1) شنو هو PiRC؟

**PiRC** (Pi Request for Comments) هو **معيار رسمي لتصميم وإصدار Tokens** داخل Pi Network، قدّمه فريق Pi Core بقيادة Nicolas Kokkalis.

بالدارجة: **قواعد لازم كل مشروع يتبعها باش يصدر Token خاص بيه داخل الإيكوسستم.**

### المبدأ الأساسي: Product-First

```
الإيكوسستمات الأخرى (Solana/BNB):
  Whitepaper → Token → تطبيق (ربما)

Pi Network (PiRC):
  تطبيق شغال + مستخدمين حقيقيين → Token
```

**يعني**: ما يقدرش مشروع يصدر Token فPi إلا إذا عندو **تطبيق فعلي يشتغل** بمستخدمين حقيقيين.

### قواعد PiRC الأساسية

| القاعدة | التفاصيل |
|---|---|
| **Product-First** | لازم يكون كاين تطبيق شغال قبل التوكن — ماشي whitepaper فقط |
| **Anti-Rug Pull** | عائدات التوكن ما تروحش للفريق مباشرةً |
| **السيولة الدائمة** | كل Pi المجموع من التوزيع يدخل **Pool سيولة دائم** |
| **Supply واضح** | إجمالي التوكن، التوزيع، الـVesting — كلهم محددين مسبقاً |
| **Anti-Sybil** | آليات تمنع واحد يشتري بحسابات متعددة |

## 2) Pi Launchpad — كيفاش يشتغل؟

**Pi Launchpad** هو التطبيق الرسمي اللي ينفذ PiRC. هو **البوابة الوحيدة** لإطلاق Tokens رسمية داخل الإيكوسستم.

### مسار إطلاق توكن عبر Pi Launchpad

```
[1] المشروع يتقدم
    └── تطبيق شغال + مستخدمين + ملف PiRC

[2] المجتمع يقيّم
    └── Ecosystem Directory Staking (Pioneers يستيكوا Pi لدعم المشروع)

[3] التوزيع يبدأ
    └── Pioneers يستيكوا Pi للحصول على توكنات المشروع

[4] السيولة تُبنى تلقائياً
    └── كل Pi المجموع → Pool سيولة دائم (Token/Pi)

[5] التداول يبدأ
    └── فPiDEX — مع سيولة أساسية موجودة من اليوم الأول
```

### PiPower — الأولوية في التوزيع

مش كل Pioneer يأخذ نفس الكمية — الأولوية تحدد بـ**PiPower**:

| عامل | التأثير |
|---|---|
| **مدة الـLockup** | كلما طولت القفل، كلما زاد PiPower ديالك |
| **نشاط الإيكوسستم** | كثرة الاستخدام، التصويت، الدعم = PiPower أعلى |
| **KYC مكتمل** | شرط أساسي |
| **سبق المشاركة** | Pioneers اللي يشاركوا في إطلاقات سابقة |

## 3) لماذا هاد النموذج مختلف عن Solana / BNB؟

### المقارنة

| وجه المقارنة | Pi Launchpad (PiRC) | Pump.fun (Solana) | Binance Launchpad |
|---|---|---|---|
| **شرط الإطلاق** | تطبيق شغال إلزامي | لا شرط — أي أحد | مشاريع مختارة من Binance |
| **عائدات التوكن** | → Pool السيولة مباشرةً | → الفريق (rug pull محتمل) | → الفريق |
| **السيولة** | مضمونة من اليوم الأول | صفر — يبنيها الفريق كيف يشاء | تعتمد على Binance |
| **التوزيع** | PiPower (نشاط + lockup) | FCFS (أول من يشتري) | Lottery أو stake BNB |
| **الهدف** | utility للتطبيق | speculation بحتة | capital raising |
| **حماية المستخدم** | Anti-sybil + product-first | لا شيء | جزئية |

### الخلاصة الجوهرية

> **Pi Launchpad مبني أساساً لمنع الـSpeculation من يدمر قيمة الإيكوسستم** — في حين Pump.fun مثلاً مبني خصيصاً للـspeculation.

هاد الفرق **يحدد سلوك السوق**: فPi، Token كيُطلق مع **سيولة حقيقية + تطبيق شغال + مستخدمين**. فسولانا أو BNB، Token كيطلق ومعروف لحد — كل شي speculation.

## 4) كيفاش يُبنى Pool السيولة تلقائياً؟

هاد الجزء مهم لفهم **لماذا Spread يكون أضيق** في بداية توكنات PiRC مقارنةً بتوكنات Pump.fun:

```
مثال توضيحي (أرقام افتراضية):
━━━━━━━━━━━━━━━━━━━━━━━━
Pioneers يستيكوا: 1,000,000 Pi
Token يُوزَّع: 10,000,000 TOKEN

عائدات الـStaking:
  ├── تذهب لـPool السيولة: TOKEN/Pi
  └── Pool يُحدد: 1 Pi = 10 TOKEN (كسعر أولي)

النتيجة:
  Pool يبدأ بـ: 1,000,000 Pi + 10,000,000 TOKEN
  TVL أولي: 2,000,000 Pi (قيمة مضاعفة)
  السعر: مدعوم بسيولة حقيقية من اليوم الأول
━━━━━━━━━━━━━━━━━━━━━━━━
```

**هاد الفرق**: فPump.fun، Pool يبدأ بـ2-3 SOL فقط. فPi Launchpad، Pool يبدأ بكل Pi المجموع من المجتمع.

## 5) مثال حي — IRRA و SLICE (Testnet)

### IRRA (Pi Day Testnet)
- أول توكن تجريبي على Launchpad Testnet
- هدفه تعليمي: شرح الآلية للـPioneers
- استعمل Test-Pi فقط، ما كانش توكن حقيقي

### SLICE (Slice of Pi App)
- مرتبط بتطبيق **Slice of Pi** — تطبيق شغال فعلاً
- نموذج محسّن: Pioneer يستيك Pi ويحجز، بعدا يؤكد
- يُمثّل مفهوم **utility-first**: التوكن باش يُستعمل داخل التطبيق، ماشي للتداول البحت

> كلاهم **مؤكد رسمياً من minepi.com** كاختبارات فعلية للـLaunchpad.

## 6) صلة PiRC بـCiDi Games / ELF

فسياق ما ندرسو في هاد الريبو:

- **CiDiCoin** إذا صار توكن رسمي، سيمر عبر PiRC → يعني سيولة مضمونة من اليوم الأول
- **Elf Sigil** كأصل قابل للتداول، سيستفيد من Pool السيولة الأولي
- **المسار**: Pioneers يستيكوا Pi → Pool يُبنى → Elf Sigil يبدأ تداوله بـSpread أضيق

هاد الشيء **يُعدّل جزء من تحليل FIRST_MINUTES.md**: إذا كان الأصل مر عبر PiRC Launchpad، السيولة الأولية غادي تكون أحسن من أصل بدون Launchpad.

راجع [`docs/FIRST_MINUTES.md`](FIRST_MINUTES.md) و [`docs/CASE_CIDI.md`](CASE_CIDI.md).
